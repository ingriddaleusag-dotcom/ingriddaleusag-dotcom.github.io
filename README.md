# Koreplay official domain

This repository serves the account-level GitHub Pages domain for Koreplay. It contains the Android Digital Asset Links association for the official signed Android app.

- [Product website](https://ingriddaleusag-dotcom.github.io/Koreplay-site/)
- [Privacy policy](https://ingriddaleusag-dotcom.github.io/Koreplay-site/privacy/)
- [Trakt integration](https://ingriddaleusag-dotcom.github.io/Koreplay-site/trakt/)
- [Android association file](https://ingriddaleusag-dotcom.github.io/.well-known/assetlinks.json)

Application source code and install packages are privately distributed. This repository contains public website information and domain verification only.

The files are maintained by the Koreplay website publishing workflow.
